# Malibooze website

Static website draft for Malibooze, Discount Liquor, and University Liquor.

Open `index.html` in a browser, or serve this folder:

```sh
cd /home/mike/Work/maliboozeWebsite
python -m http.server 8000
```

Then visit http://localhost:8000.

The three Facebook URLs from `notes.txt` are linked in the store cards and updates section, including without JavaScript. The third supplied URL is assigned to University Liquor based on file order. Facebook page contents could not be retrieved. Store addresses and phone numbers were subsequently added from public business listings; hours remain unverified. Update links in both `index.html` and the `stores` array in `main.js` when needed.

Before launch, confirm the domain spelling supplied as `maliboozeliguor.com`, official store names, Facebook pages, and hours. Confirm the directory-sourced addresses and phone numbers with the owner. The draft does not assert unverified store details. Upload index.html, style.css, main.js, and the three logo images to the domain's web host to deploy. No deployment or domain configuration has been performed.

The fonts load from Google Fonts, with system fallbacks when offline.
